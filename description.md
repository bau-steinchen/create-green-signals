# Create Green Signals

Makes the nixie tubes on **Create** train signals glow **green** instead of white when the track is clear — just like it used to be possible with Steam 'n' Rails.

- 🟢 Green when the block section is free
- 🔴 Red and 🟡 yellow stay exactly as in Create
- The glow around the tube is green as well
- Pure resource pack: no code, no mixins, client-side only

**Requires:** Minecraft 1.21.1 · NeoForge · Create 6.0.x
